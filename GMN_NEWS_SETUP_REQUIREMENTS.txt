========================================================
GMN NEWS — LOCAL DEV SETUP REQUIREMENTS
========================================================
Keep this file somewhere safe (not just on the machine
you're about to reset). It has everything needed to get
GMNews2 running again from scratch.

--------------------------------------------------------
1) SOFTWARE TO INSTALL FIRST
--------------------------------------------------------
- Node.js (LTS version)   -> https://nodejs.org
  (installs both `node` and `npm`)
- Git                      -> https://git-scm.com
- VS Code                  -> https://code.visualstudio.com

Verify install by running in a terminal:
  node -v
  npm -v
  git -v

--------------------------------------------------------
2) CLONE THE REPO
--------------------------------------------------------
git clone https://github.com/WolfSyn/GMNews2.git
cd GMNews2

--------------------------------------------------------
3) INSTALL PROJECT DEPENDENCIES
--------------------------------------------------------
This project uses Node/npm, NOT Python — so there is no
requirements.txt. All dependencies are listed in
package.json (already in the repo). Just run:

  npm install

This installs: React, React Router, Vite, Express, cors,
dotenv, @supabase/supabase-js, node-fetch, sanitize-html,
@mozilla/readability, jsdom, nodemon, concurrently, ESLint,
and everything else package.json lists.

--------------------------------------------------------
5) RUN THE DEV SERVER
--------------------------------------------------------
  npm run dev

This runs BOTH the Vite frontend and the Express backend
together (via `concurrently`). You should see:
  CLIENT | Local: http://localhost:5173
  SERVER | GMN News API v3 -> http://localhost:3000

If you ever need to run them separately:
  npm run dev:client     (Vite frontend only)
  npm run dev:server     (Express backend only, via nodemon)

--------------------------------------------------------

--------------------------------------------------------

Render environment variables must match the .env values
above (same keys, same values) EXCEPT do NOT add
VITE_API_BASE on Render — the frontend defaults to
gmnews2.onrender.com automatically in production.

Supabase Authentication -> URL Configuration should have:
  Site URL:       https://gmnnews.org
  Redirect URLs:  https://gmnnews.org
                  http://localhost:5173   (only while testing locally)

--------------------------------------------------------
7) IF SOMETHING WON'T START
--------------------------------------------------------
- "Cannot find module" errors -> re-run `npm install`
- Blank page in browser        -> check browser console (F12)
  for errors; usually a missing/incorrect .env value
- Port 3000 already in use     -> close other terminals running
  the server, or change PORT in .env
- Supabase "supabaseUrl is required" -> .env is missing or in
  the wrong folder (must be in project ROOT)
